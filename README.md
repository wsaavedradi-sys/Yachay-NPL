# Yachay NPL

Chatbot bilingüe desarrollado con Streamlit.

## Ejecutar localmente

1. Cree y active un entorno virtual.
2. Instale las dependencias:

   `pip install -r requirements.txt`

3. Copie `.streamlit/secrets.example.toml` como `.streamlit/secrets.toml`.
4. Añada al menos una clave API al archivo `secrets.toml`.
5. Ejecute:

   `streamlit run app.py`

No envíe el archivo `.streamlit/secrets.toml` ni la carpeta `venv/`.
